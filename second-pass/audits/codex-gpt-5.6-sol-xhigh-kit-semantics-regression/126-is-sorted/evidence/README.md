# Evidence index

- `stage1_integrity.log`, `stage1_provenance_supplement.log`: required-artifact
  types, trusted prompt/translator identity, recursive supplied-semantics
  manifest/diff, JSON/trace parsing, and untrusted-claim summary.
- `stage2_fidelity.log`: trusted translator regeneration and independent Python
  differential result. Inputs are fixed by `differential_input_scope.json`;
  execution is `differential_test.py`.
- `stage3_reconstruction.log`: clean LLVM/Haskell builds, concrete driver, base
  loop proof, and full entry proof. `concrete_driver.py` is the preserved
  reviewer test source.
- `stage4_adequacy.log`: concrete claim substitutions and two K adequacy
  witnesses (`adequacy-witness.k`, `adequacy_substitution.py`).
- `k_rule_inventory.txt`: exhaustive line-addressed K declaration/rule
  inventory generated by `k_inventory.py`.
- `rule_review_ledger.md`, `used_construct_map.md`,
  `stage5_ledger_check.log`: 955/955 static decisions and the real-program
  operational slice.
- `stage5_body_sensitivity.log`, `verification-body-mutation.patch`: successful
  build and expected semantic proof failure after changing the program
  initialization.
- `stage6_nonvacuity.log`, `spec-fresh-vacuity.k`: fresh false-result mutation,
  successful dry-run build, and expected stuck result obligation.

Every `stage*.log` was captured from the correspondingly named reviewer shell
script with command tracing and exit statuses. Large compiler output is bounded
in the captured transcripts; full temporary raw logs remain only in scratch.
