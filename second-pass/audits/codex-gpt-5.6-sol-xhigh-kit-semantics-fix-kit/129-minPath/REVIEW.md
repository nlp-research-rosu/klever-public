## 2. Program fidelity and candidate-versus-canonical checks

### Natural-language contract

For a square `N×N` grid with `N ≥ 2` containing each integer `1..N²` exactly once, and a positive integer `k`, return the lexicographically smallest sequence of cell values among all edge-adjacent paths visiting exactly `k` cells. Cells may be revisited and the path may not leave the grid. The answer is unique.

Because `1` is the unique global minimum, a lexicographically minimal path starts at the cell containing `1`. If `k > 1`, its second value is the least value `m` among that cell's edge-neighbors. From `m`, the least possible next value is `1`, and this pair can be revisited. Thus the intended result is `[1, m, 1, m, ...]`, truncated to length `k`.

The trusted canonical implementation scans for `1`, computes the minimum of its legal neighbors, and emits that alternating pattern. The generated implementation uses a different but equivalent organization: it first records the unique coordinates of `1`, initializes `neighbor` to `N²+1`, conditionally minimizes over the four legal directions, and then emits the same alternating pattern. On the intended domain, the unique-`1` condition makes the fact that the scan does not break immaterial.

### Pinning and result constraint

The three entry claims start with `#loadAll(MINPATH-PROGRAM) ~> Call(Name("minPath"), ...)`. Fresh KAST comparison establishes that this is the submitted `solution.mpy`. Normal MPY rules load the function into the module scope, look up that binding, evaluate arguments left-to-right, allocate a call frame, bind `grid` and `k`, execute the body, and return. There is no proof-local rule intercepting `Call`, `#applyK`, the scan, or the neighbor tests.

The whole-function posts are not tautologies or implications with a free result. They require the returned value to be `ref(0)` and constrain the exact heap content at that reference. They also require empty stack, `noRet`, `NoExc`, exit code `0`, and the expected heap allocation count. The final scopes map is existential, which intentionally omits an unobservable module-scope detail; this does not loosen the returned list or any error/control outcome relevant to the contract.

The helper claim begins at the exact internal `#loop` form produced by `For` after evaluation of `range(k)`. Its body is constructor-for-constructor the actual final loop. It reads `neighbor`, `answer`, and `i`, writes `i` in the current scope, and mutates only the list at heap location `H`; its post constrains that list. It is a sound local invariant, but it is not a general function-entry theorem.

### Material adequacy gap

There is no whole-function claim for arbitrary `N≥2` or arbitrary positive `k`. `answer-loop` establishes the general alternating append only after `neighbor` has already been computed; it does not establish that the preceding scan finds `1` or that the four guarded updates compute the least legal neighbor on an arbitrary grid. `all-valid-2x2-k3` establishes those facts only for the 24 valid `2×2` grids and only at `k=3`. The ground examples add `3×3` evidence but no symbolic domain.

The informal reasoning at the start of Stage 2 and the differential tests strongly support general correctness, but neither substitutes for a general K entry claim. This is the decisive concern.

Stage 4 result: **REAL-PROGRAM PINNING PASS; FULL-INTENT ADEQUACY FAIL**.

### Complete proof-local extension review

Candidate `verification.k` contributes exactly three syntax declarations and ten rules:

1. `altSuffix(Int,Int,Int) [function,total]` with three rules.
   - `I≥K` returns the empty sequence.
   - `I<K ∧ pyMod(I,2)=0` emits `1` and recurses at `I+1`.

2. `neighbor2(A,B,C,D) [function,total]` with four rules.
   - If `A=1`, return `min(B,C)`.
   - Else if `B=1`, return `min(A,D)`.
   - Else if `C=1`, return `min(A,D)`.

   - Guards are exhaustive/disjoint on all integer inputs. 3. Two `[simplification]` rules for `valSeqConcat`.
   - `concat(concat(A,B),C) = concat(A,concat(B,C))` is associativity of the supplied inductive `ValSeq` concatenation.
   - `concat(A,empty)=A` is right identity.
   - Both are ordinary inductive equalities. Their overlaps with the supplied left-recursive equations and with each other agree. The orientations reduce left nesting or remove a trailing identity and introduce no inconsistent cycle.

4. `MINPATH-PROGRAM [macro]` with one expansion rule.
   - This is compile-time syntax, not a runtime rewrite or oracle. Fresh expanded KAST is identical to the regenerated submitted program. Changing the program source would change the KAST identity check; the macro does not make arbitrary bodies equivalent.

## 7. Proven versus assumed accounting

Conditioned on the trusted supplied MPY semantics and K toolchain, the successful reachability claims establish partial correctness of:

- the exact final answer loop for every integer state satisfying `0≤I≤K`: if it terminates, it appends the alternating suffix described by `altSuffix(I,K,M)` to the existing list;
