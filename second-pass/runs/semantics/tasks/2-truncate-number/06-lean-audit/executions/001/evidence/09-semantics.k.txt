    10	// Files (dependency order — everything imports MPY-CORE):
    11	//   semantics/syntax.k         MPY-SYNTAX       AST productions
    12	//   semantics/core.k           MPY-CORE         values, config, load, lookup, shared helpers   [required]
    13	//   semantics/iter.k           MPY-ITER         the iterator protocol (#iterNext/#iterYield/#iterDone) decl
    14	//   semantics/range.k          MPY-RANGE        rangeObj: inRange / rangeLen / its #iterNext
    15	//   semantics/operators.k      MPY-OPERATORS    operator DISPATCH (UnaryOp/BinOp/Compare/BoolOp) — domain files own the cases
    16	//   semantics/int.k            MPY-INT          Int operator cases; floored // and % (pyMod)
    17	//   semantics/bool.k           MPY-BOOL         Bool operator cases + truthy not/and/or (BoolOp)
    18	//   semantics/float.k          MPY-FLOAT        Float Val: literal + opaque float ops ([concrete] for krun)
    19	//   semantics/str.k            MPY-STR          str(IntSeq): literal, +, ==, in
    20	//   semantics/set.k            MPY-SET          set(str): distinct char codes (len / membership)
    21	//   semantics/list.k           MPY-LIST         ListExpr, list(ValSeq): +, ==, in
    22	//   semantics/tuple.k          MPY-TUPLE        TupleExpr, tuple ==, target-binding + unpacking
    23	//   semantics/subscript.k      MPY-SUBSCRIPT    Subscript indexing + Slice
    24	//   semantics/comprehension.k  MPY-COMPREHENSION  list comprehensions [ELT for T in ITER if COND]
    25	//   semantics/methods.k        MPY-METHODS      pure str methods: is*/lower/upper/swapcase/startswith
    26	//   semantics/controls.k       MPY-CONTROLS     Assign/AugAssign, If, IfExp, For, While, break/continue
    27	//   semantics/functions.k      MPY-FUNCTIONS    def / call / return (frame stack)
    28	//   semantics/builtins.k       MPY-BUILTINS     builtins as calls: len/sum/abs/min/max/ord/chr/str
    29	//   semantics/call.k           MPY-CALL         ALL Call routing + argument evaluation
    30	//   semantics/sort.k           MPY-SORT         trusted sorted(): opaque sortVS + concrete insertion sort
    31	//   semantics/assert.k         MPY-ASSERT       Assert oracle (smoke programs only)
