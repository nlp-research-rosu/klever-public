NOTE
The shim source is preserved as evidence/app_path_shim.c. It intercepts only
/proc/<pid>/exe readlink/readlinkat calls made by processes named "lean" or
"lake", returning the pinned /opt/elan toolchain binary path. All other calls
use the original libc functions. It does not alter project files, Lean terms,
generator/checker sources, or compiler output.
