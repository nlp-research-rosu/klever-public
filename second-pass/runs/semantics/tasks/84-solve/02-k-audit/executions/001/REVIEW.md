## 2. Program fidelity and candidate-versus-canonical checks

### Contract

return the ordinary base-2 numeral for that sum as a string, with no `0b`
prefix. The documented examples are:

- `1000 -> "1"`
- `150 -> "110"`
- `147 -> "1100"`

Although the prose says “positive,” its explicit constraint includes zero; the
audited domain therefore includes `N=0`, whose result is `"0"`.

disagree outside that domain, but out-of-domain behavior is not claimed.
