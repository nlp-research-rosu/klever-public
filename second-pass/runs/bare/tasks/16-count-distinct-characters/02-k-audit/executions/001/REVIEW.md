## 2. Program fidelity and candidate-versus-canonical checks

From the trusted prompt and canonical implementation, the entry point accepts a
Python `str` and returns the number of distinct characters after applying
Python's case-lowering operation. Equivalently, the trusted canonical result is
`len(set(string.lower()))`. The documented examples are:

- `"xyzXYZ"` returns `3`.
- `"Jerry"` returns `4`.

The intended domain is not restricted to ASCII. The type is Python `str`, and
the trusted canonical implementation uses Python's Unicode-aware `.lower()`.

```python
def count_distinct_characters(string: str) -> int:
```

It preserves the required entry point and implements the same expression as the
trusted canonical function.

```text
cmp -s /tmp/audit-work/generated/solution.mpy /candidate/solution.mpy
```

with SHA-256
`2e97b9f354373f39763938a074e4f09fb6a259868fdc704ed07b670ed65ccfc9`.
