Independent differential input scope

Oracle:
  A separately written prefix accumulator that returns true exactly when a
  running total is strictly negative.

Named cases:
  []
  [1, 2, 3]
  [1, 2, -4, 5]
  [-1]
  [0]
  [5, -5]
  [5, -5, -1]
  [-1, 100]
  [10**100, -(10**100)]
  [-(10**100), 10**100]

Exhaustive generated cases:
  Every list of lengths 0 through 5 over integer elements -3 through 3.

Broader seeded cases:
  PRNG seed 0x3B310; 1000 lists of length 0 through 30. Each element is either
  sampled from {-(10**100), -(2**63), -10**9, -1, 0, 1, 10**9, 2**63,
  10**100} with probability 1/3, or uniformly from [-10**12, 10**12].
