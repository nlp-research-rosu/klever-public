The complete differential input set is generated deterministically by
differential_test.py in this directory:

1. The three prompt examples.
2. Eleven explicit empty/singleton/equal-end/unequal-end/even/odd/extreme-int
   branch-boundary cases.
3. Every list of length 0 through 8 over {-1, 0, 1}.
4. Two thousand pseudo-random lists from seed 730073, with lengths 0 through
   128 and elements from {-2**63, -7, -1, 0, 1, 7, 2**63-1}.
5. Two lists of length 2501, because the prompt gives no maximum length and
   this boundary tests the recursive rewrite against normal CPython recursion.

The run prints a SHA-256 digest over the ordered JSON encoding of every input,
so reruns can confirm the exact generated set without preserving a huge fixture.
