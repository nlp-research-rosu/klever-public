The Lean 4.22 runtime implementation of lean_io_app_path reads
/proc/<getpid()>/exe. This sandbox exposes /proc/self/exe but does not expose
the namespace PID as /proc/<pid>, causing IO.appPath and Lake installation
detection to fail.

input, generated source, checker, or toolchain file.
