## 2. Program fidelity and candidate-versus-canonical checks

Status: program fidelity passes.

### Contract

The trusted [docstring](/reference/prompt.py:2) fixes the following domain and
result:

- `grid` is an `N` by `N` grid, `N >= 2`, containing each integer from 1 through
  `N*N` exactly once;
- `k` is a positive integer;
- a path visits exactly `k` cells, may revisit cells, moves only across shared
  edges, and stays in the grid;
- return the lexicographically least sequence of visited cell values.

The two documented examples require `[1,2,1]` for the ordered 3-by-3 grid with
`k=3` and `[1]` for the second grid with `k=1`.  There is no docstring/canonical
contradiction relevant to this submission.

The candidate [solution.py](/candidate/solution.py:1) scans for the unique cell
containing 1, computes the least value `M` among its orthogonal neighbors, and
returns the alternating prefix `1,M,1,M,...` of length `k`.  This is correct on
the full documented domain: a lexicographically least path must begin with the
global minimum 1; from 1 its least second value is `M`; from `M`, returning to
the adjacent global minimum 1 is least; the same argument then repeats.  The
`k=1` case is the singleton `[1]`.

### Domain and result adequacy

`validPerm(P,N*N)` means the flattened sequence has length `N*N`, every member
is in `1..N*N`, and no member repeats.  It is therefore exactly a permutation,
not a sample or bounded family.  `gridRows(P,N)` constructs exactly `N` rows of
length `N`.  The target quantifies arbitrary mathematical integers `N>=2` and
`K>0`.  The explicit `oneRow` and `oneCol` bounds are logical consequences of
the permutation premise; they do not narrow the source contract.

`?OUT` is not free: the post-state heap binds reference 0 to `list(?OUT)`, and
the `ensures` clause constrains it through `finishRel`.  For
`R=(K-pyMod(K,2))/2`, `finishRel` recursively requires `R` copies of the pair
`1,M`, then appends 1 iff `K` is odd.  Thus the output has exactly length `K`
and the required values.  The result is neither tautological nor a one-way
condition that permits arbitrary output.

Every entry precondition is satisfiable.  Concrete witnesses for all eight
claims are recorded in
[stage4-witnesses.log](/audit-output/evidence/stage4-witnesses.log), generated by
[adequacy_witness.py](/audit-output/evidence/adequacy_witness.py).  In
particular, `N=2`, `P=[1,2,3,4]`, and `K=3` satisfies the target; substituting it
into the claimed summary gives `[1,2,1]`, identical to both Python
implementations.
