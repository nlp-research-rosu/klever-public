Lean PID-namespace compatibility
================================
The sandbox shell reports a PID for which /proc/<pid>/exe is absent, while
/proc/self/exe works. Lean 4.22 consults /proc/<getpid>/exe to find its
installation. The audit therefore compiled evidence/pid-namespace-shim.c and
used only this execution environment for Lean/Lake commands:

  LD_PRELOAD=/tmp/audit-work/libreadlink-self.so
  LAKE_HOME=/opt/elan/toolchains/leanprover--lean4---v4.22.0
  LEAN_SYSROOT=/opt/elan/toolchains/leanprover--lean4---v4.22.0
  PATH=/opt/runtimeverification-k/pyk/.venv/bin:/opt/elan/toolchains/leanprover--lean4---v4.22.0/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

The shim changes only readlink("/proc/<pid>/exe") to
readlink("/proc/self/exe"). It does not alter Lean sources, declarations,
toolchain contents, project files, proof terms, or command output.
