Command:
  python - <<'PY'
  import os
  print(os.getpid(), os.readlink('/proc/self/exe'), os.readlink(f'/proc/{os.getpid()}/exe'))
  PY
Result:
  FileNotFoundError: [Errno 2] No such file or directory: '/proc/3/exe'

The audit PID namespace reports an inner PID (3), while its read-only /proc is
mounted from the outer namespace. Lean 4.22 uses /proc/<getpid()>/exe. The
narrow shim in 05-lean-proc-self-shim.c redirects only that exact self lookup
to /proc/self/exe. No mounted evidence was changed.
