These are the authentic hashes recorded in generator-manifest.json. The
failure is therefore in the selected producer/output, not missing or
mismatched provenance.

Relevant generation-time `_widen_projection` behavior:

    projected = definition.let(
        symbols=symbols, functions=functions
    ).project_to_symbols()
    retained_sorts = set(projected.sorts) | extra_sorts
    sorts = FrozenDict(
        (sort, declaration)
        for sort, declaration in definition.sorts.items()
        if sort in retained_sorts
    )
    subsorts = FrozenDict(
        (
            supersort,
            frozenset(
                subsort
                for subsort in subsort_set
                if subsort in sorts
            ),
        )
        for supersort, subsort_set in definition.subsorts.items()
        if supersort in sorts
    )

The retained-sort set is not closed over subsorts. Filtering then silently
deletes `SortStr < SortIterable` and `SortStr < SortVal`, along with the only
constructor of SortStr. This exactly matches both the independently
reconstructed projection and the selected generated Lean project.
