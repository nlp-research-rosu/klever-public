DIAGNOSIS
The audit sandbox exposes host PIDs through /proc but getpid() returns the
process's inner namespace PID. For example, /proc/self/status showed a host
Pid and a distinct inner NSpid, while /proc/<inner-pid>/exe did not exist.
Lean 4.22 therefore could not locate its own executable. A narrow LD_PRELOAD
shim was compiled from /tmp/audit-work/proc-self-fix.c (preserved as
/audit-output/evidence/scripts/proc-self-fix.c); it returns the host
Pid parsed from /proc/self/status and redirects only /proc/<number>/exe
realpath requests to /proc/self/exe. The shim was applied only to Lean/Lake
children; no mounted input, trusted checker, generated source, or toolchain
binary was modified.
