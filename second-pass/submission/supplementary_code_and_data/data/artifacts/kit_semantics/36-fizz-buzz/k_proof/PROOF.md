## What is proven

Under the supplied `MPY` semantics, the exact `fizz_buzz` closure generated
from `solution.py` is partially correct for every K `Int` input. If the call
terminates, it returns the number of decimal digit `7`s occurring in the
nonnegative integers below `n` that are divisible by 11 or 13. For `n <= 0`,
the result is zero, matching Python's empty `range(n)`.

The theorem observes the returned integer and also constrains the call to
restore the module environment, scope allocator, empty heap, empty stack,
return state, exception state, and exit code shown in the entry claim.
Temporary locals are deallocated by the supplied call semantics.

This is a partial-correctness result, as defined by the Kit workflow. A
separate well-founded argument supports termination: the outer loop decreases
a positive `i` by one, and the inner loop replaces a positive `x` by
`x // 10`, which is strictly smaller and nonnegative.

## Formal claim

`SPEC.fizz-buzz` starts from `Call(Name("fizz_buzz"), Int(N))` with
`"fizz_buzz"` bound to the exact closure body in `solution.mpy`. It reaches an
integer `R` satisfying:

```text
R = fizzResult(0, N)
```

The mathematical summaries are accumulator recurrences. Let
`b(x) = 1` when `x mod 10 = 7`, and `0` otherwise, and let
`q(x) = x // 10` for positive `x`.

```text
digitResult(c, x) = c                                      when x <= 0
digitResult(c, x) = digitResult(c + b(x), q(x))            when x > 0

fizzResult(c, n) = c                                       when n <= 0
fizzResult(c, n) =
  fizzResult(digitResult(c, n - 1), n - 1)                 when n > 0
    if (n - 1) is divisible by 11 or 13
  fizzResult(c, n - 1)                                     otherwise
```

The equations in `verification.k` are oriented as folds so symbolic calls do
not unfold forever. Their orientation changes proof search, not their
mathematical meaning. `SPEC.inner-loop` proves the first recurrence against
the real inner `#while`; `SPEC.outer-loop` proves the second and uses the
inner claim; the entry claim executes lookup, argument evaluation, call-frame
creation, the exact function body, return, and frame removal.
